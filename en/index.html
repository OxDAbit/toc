Every window, in its place.

toc lives in your Mac's menu bar and moves the active window to halves, thirds or quarters of the screen with a keyboard shortcut, or when you drag it to an edge.

Download toc Build from source

For macOS 26 or later, on Intel and Apple silicon Macs. Version 0.0.1.

Drag it to the edge

Take a window to the edge of the screen and toc shows you where it will land. Let go and it snaps into place.

When you resize a window from its edge, toc stays out of the way.

It doesn't go quiet after sleep

On some Macs running macOS 26, after waking from sleep, macOS stops giving Accessibility apps access to windows. Window managers stop responding without saying why, and only a restart fixes it. toc was built to speak up when that happens.

  1. Your Mac wakes up and, three seconds later, toc checks that Accessibility responds.
  2. If macOS returns the app instead of its windows, toc's icon changes to ⚠︎ and explains what happened.
  3. Finder, Safari, System Settings and other scriptable apps keep moving through Apple Events.
  4. For everything else, toc tells you how to recover: restart your Mac, because logging out is not enough.

If you want to dig in, “Copy diagnostics” in toc's menu gives you a report of what macOS sees.

Install toc

Download

Published versions are on the repository's releases page on GitHub.

See releases on GitHub

toc is signed with its own certificate, not one from Apple. The first time you open it, macOS will block it: go to System Settings → Privacy & Security and click “Open Anyway”.

Build from source

You need macOS 26 and Xcode 26. The script builds a universal binary, signs it and copies it to Applications.

  1. Clone the repository:
    git clone https://github.com/OxDAbit/toc.git
  2. Go into the folder:
    cd toc
  3. Build and install:
    ./scripts/build-app.sh --install
  4. Open toc:
    open /Applications/toc.app

After installing

Give toc the Accessibility permission when it asks. To open it when your Mac starts, check “Open at login” in its menu.
